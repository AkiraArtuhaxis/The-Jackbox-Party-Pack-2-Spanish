# The Jackbox Party Pack 2: traducción a español

Parche de traducción no oficial de [Jackbox en español](https://traducciones.jackbox.lol/) para The Jackbox Party Pack 2. Este repositorio es utilizado por [Jackbox Utility](https://github.com/JackboxUtility).

- **Estado de traducción:** Todos los juegos han sido traducidos.
- **Estado de doblaje:** Earwax y Subastardos (Bidiots) tienen doblaje.
- **Versión:** 21.2-ES
- **Plataformas soportadas:** Steam, Epic Games Store, Nintendo Switch

## Cómo utilizar

Para crear un nuevo parche, se siguen los siguientes pasos:

1. Colocar el contenido de los parches en sus respectivos directorios.
2. Abrir el respectivo bat, que genera los zips correspondientes para cada versión soportada.
3. Hacer release en GitHub y subir los archivos generados.
4. Completar los datos: número de versión, título y texto que detalle qué se hizo en la release.
5. En GitHub subir los archivos ahora cambiados (con eso el archivito de versión se cambia, que lo usa la Utility), publicar la release y listo.
6. Al generar un release nuevo, redactar las patch notes correspondientes y publicar en la página.
